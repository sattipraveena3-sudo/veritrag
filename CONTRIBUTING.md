# Contributing

Thank you for improving VeriRAG.

1. Fork the repository and create a focused feature branch.
2. Install development dependencies with `make install`.
3. Add or update tests for every behavioural change.
4. Run `make check` before opening a pull request.
5. Keep public APIs typed and document material design decisions in the PR description.

Bug reports should include a minimal reproduction, Python version, operating system, and relevant logs with secrets removed.
