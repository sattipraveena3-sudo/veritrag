# Project #1 Portfolio Notes

## Title
VeriRAG — Evidence-First Reliability Gateway for RAG and LLM Applications

## Problem statement
RAG systems can retrieve relevant text yet still produce unsupported or overstated answers. VeriRAG provides a provider-neutral reliability layer that ingests trusted knowledge, performs hybrid retrieval, decomposes generated answers into claims, checks each claim against evidence, calculates an explainable risk score, persists provenance, and can fail a CI pipeline when an answer is insufficiently supported.

## Global Talent positioning
- Demonstrates original engineering around a current production AI reliability problem rather than a tutorial chatbot.
- Shows end-to-end technical ownership across retrieval, evaluation, API design, persistence, packaging, testing, CI/CD, containerisation, and developer experience.
- Is structured as an open-source project that can generate external evidence through stars, forks, contributors, issue discussions, benchmark adoption, technical writing, and third-party testimonials.
- Creates a credible platform for follow-on public benchmarks or research, connecting applied AI engineering with measurable impact.

## Repository description
Evidence-first reliability gateway for RAG/LLM apps: hybrid retrieval, claim-level support auditing, provenance, risk scoring, REST API, CLI and CI quality gates.
