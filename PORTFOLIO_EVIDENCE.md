# Portfolio and Visa Evidence Notes

## Repository description
Evidence-first reliability gateway for RAG/LLM apps: hybrid retrieval, claim-level support auditing, provenance, risk scoring, REST API, CLI and CI quality gates.

## Reusable evidence notes
- Designed and built an original open-source AI reliability gateway that audits RAG/LLM outputs claim-by-claim against retrieved evidence and returns explainable pass/fail risk decisions.
- Implemented the complete production stack: custom BM25 retrieval, pluggable vector embeddings, hybrid ranking, claim verification, SQLite provenance storage, FastAPI, CLI, Docker, tests, strict typing and GitHub Actions CI.
- Created a provider-neutral architecture that other developers can integrate as a pre-deployment or CI quality gate instead of coupling evaluation to a single commercial LLM vendor.
- Published the work for external adoption and independent validation; impact should be evidenced with real usage metrics such as stars, forks, contributors, downloads, benchmark results, issue discussions, citations, talks or third-party testimonials.
